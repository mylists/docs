# Managing Personal Tracking Lists

Personal lists track your unique relationship with catalog media. Each user maintains an isolated set of list entries referencing catalog items.

---

## Status Classification

Every item on your list belongs to one of five standard lifecycle statuses:

| Status Key | Display Name | Applicable Categories | Meaning |
| :--- | :--- | :--- | :--- |
| `watching` / `reading` | **Currently Active** | Movies, TV Shows, Books | Media currently in progress |
| `completed` | **Completed** | All Categories | Media finished from start to finish |
| `on_hold` | **On Hold** | All Categories | Paused temporarily with intent to resume |
| `dropped` | **Dropped** | All Categories | Discontinued before finishing |
| `plan_to_watch` / `plan_to_read` | **Plan to Consume** | Movies, TV Shows, Books | Backlog items saved for future consumption |

---

## Tracking List Views & Filters

On the **My List** tab:
1. **Status Filter Buttons**: Quick tabs at the top let you filter by `All`, `Watching/Reading`, `Completed`, `On Hold`, `Dropped`, and `Plan to Watch/Read`.
2. **Dynamic Progress Counters**: Shows the number of items in each status pill.
3. **Card and Table Views**: Toggle between visual card grid view (with posters and progress bars) or compact tabular view for high-density management.

---

## Bulk Operations

For power users with large lists, MTVL supports batch operations:
- **Bulk Status Update**: Select multiple cards and change their status (e.g. mark 10 movies as *Completed*) with a single action.
- **Bulk Removal**: Remove multiple items from your personal list simultaneously without affecting the public catalog.
